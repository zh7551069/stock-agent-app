## 1. 策略目标与适用边界

### 1.1 市场与标的范围

| 项 | 规则 | 依据 |
|---|---|---|
| 交易所 | 沪深主板 / 创业板 / 科创板 | `stock_info.market IN ('主板','创业板','科创板')` |
| 北交所 | **排除**（因子表只取 `code like '%.SH' or '%.SZ'`） | `liupan_scan.py` 取数 SQL |
| ST / *ST | **排除**（名称含 `ST` 或 `退`） | `cur[~name.str.contains('ST|退')]` |
| 上市天数 | 盘前池 **≥120 天**；实时池 **≥60 天** | `MIN_AGE = 120` / `60` |
| 停牌 | 当日无 bar 自然不入池；不做额外标记 | 隐含 |
| 可选池规模 | 约 **4,997 只**（11-02 实测 `n_universe`） | — |

### 1.2 交易时段假设

| 时段 | 模式 | 字段语义 | 时间窗 |
|---|---|---|---|
| T-1 收盘后 | 候选池（静态截面） | 换手/量比/BOLL/RSI6 | launchd **18:35** 周一至五 |
| 09:15–09:32 | **竞价先手版** | `高开%` = 竞价价/昨收−1，`竞换` = 竞价换手% | `WIN_LO=09:15, WIN_HI=09:32` |
| 09:33–14:53 | **盘中动量版** | `涨幅` = 现价/昨收−1，`换手` = 当前累计换手% | launchd 每 **10 分钟** |
| >09:32 未显式声明 | 盘中版 + 漂移告警 | 禁止把盘中涨幅当「高开」读 | `explicit=False → warn` |

### 1.3 成功标准（主观有效点，都带证据）

| 有效点 | 量化 | 备注 |
|---|---|---|
| 候选池是**有效过滤器** | 全市场次日连板率 0.16% → 池内约 0.5%（lift ≈3×，锐利档更高） | 6,180 首板事件挖掘（2023-09~2026-10） |
| **先手分绝对值**跨日可比 | 固定锚点（非池内 min-max）→ 0.98 与 0.70 可横向比较 | 23,680 票次 P5~P95 标定 |
| 竞价先手能抓到当日最强 | 2026-10-12 09:26 → 金冠电气 0.841、果麦文化 0.769（果麦当日唯一 20% 封板） | 见 §6 |
| 板块层是有效加成 | 果麦所在「出版业」当日涨幅全行业第 1（+3.99%）、板内 3 家涨停 | v1 无板块维度 → 选不出它 |

### 1.4 明确不做的事

| 不做 | 原因 |
|---|---|
| ❌ 自动下单 / 自动改仓 | 只出「建议 + 条件单」，执行权在辉哥 |
| ❌ 把候选池当买入信号 | 是**过滤器**，不是信号；买入须逐只过 `advice_gate --pair` |
| ❌ 用「板块 T-1 强度」预测 T 日超额 | 已否证（n=503 独立日，各档 +0.06%~+0.15% 全不过门槛） |
| ❌ 用主力净额 / 概念板块当排序钥匙 | 口径错配（血证：净额第 1 = 计算机应用 +66 亿，实际涨幅第 1 = 出版业 +3.99%） |
| ❌ 用 `rc=2` 否决短线动量 | 闸门 2026-10-23 已停用；`rc` 只答「在不在四个中线通道里」 |
| ❌ 回调补数据凑结果 | 缺数一律标记 `pending` / `stale`，不插值 |

## 2. 盘前：连板候选池（`liupan_scan.py`）

### 2.1 名称与现实不符（待确认）

> 🔴 **候选池筛的不是「已经连板的股」，而是「首板前蓄势形态」** —— 允许 0 板入池。
> 连板数（zt5/zt10/zt20）**不参与入选**，只在盘中当惩罚项。
> 结论：「连板股」是产品命名；工程实现 = **次日涨停/连板潜力池**。App 文案建议改「蓄势池」或保留并加副标题。

### 2.2 涨停 / 炸板判定（口径铁律）

| 判定 | 规则 |
|---|---|
| 涨停价来源 | `limit_price.limit_pct`（**单一事实源**，含 ST 5% / 北交所 30%）；取不到才 fallback `_lim()`（10/20） |
| 已涨停 | `close >= limit_up * 0.999` |
| 当日涨停（入池剔除） | `pct_chg >= lim - 0.5` ❌ |
| 当日跌停（入池剔除） | `pct_chg <= -(lim - 0.5)` ❌ |
| 触板炸板 | `high >= limit_up*0.999` **且** `close < limit_up*0.999` |
| 一字板 | **不单独区分**（不落库为一字标记），只影响「买不进」（`locked` 区） |
| 一字/换手板是否计入连板 | **都计入**（都算 `close >= limit_up*0.999`） |

### 2.3 用到的字段（本地 DuckDB）

| 表 | 字段 | 含义 | 粒度 |
|---|---|---|---|
| `tech_factor_hfq` | `close/turnover/rsi6/ma5/ma20/vol_hand/high/low/boll_up/boll_low/pct_chg` | 后复权技术因子 | 日线 |
| `daily` | `close, high` | **未复权权威价**（绝对价位只用它） | 日线 |
| `limit_price` | `limit_pct, limit_up, prev_close` | 涨跌停档位/涨停价 | 日线 |
| `stock_info` | `code, name, list_date, industry, market` | 名称/上市日/申万行业/板块 | 静态 |
| `stock_flow_em` | `今日主力净流入额（万元）` | ⚠️ **实存单位是「元」**，显示需 ÷1e4 | 日线 |
| `minute_1min` | `dt, open/close/high/low/vol, market` | 仅回放用 | 1 分钟 |

### 2.4 派生因子（全部日线、后复权口径）

```
v30        = mean(vol_hand, 30)
vr         = vol_hand / v30                       # 量/30日均量
r30        = close / close.shift(30) - 1          # 30日涨幅
lo60       = min(low, 60)
dist_lo60  = close / lo60 - 1
hi60       = max(high, 60)
dist_hi60  = close / hi60 - 1                     # 必 ≤ -0.05（未创新高）
bp         = (close - boll_low) / (boll_up - boll_low)   # BOLL 位置 0~1
ma5_20     = ma5 / ma20 - 1
```

### 2.5 筛选规则（if-then 伪代码）

```python
# ── 硬过滤（两档共用）──
if 名称 contains ('ST','退'): skip
if 上市天数 < 120: skip
if close < ma20: skip
if dist_hi60 > -0.05: skip            # 已接近/创新高 → 不是蓄势
if pct_chg >= lim - 0.5: skip         # 当日已涨停
if pct_chg <= -(lim - 0.5): skip      # 当日已跌停 ← 2026-11-01 加（血证：10-30 文投控股 −10.13% 混进池）

# ── 档位带（band）──
锐利: turnover∈[5,12] ∧ vr∈[1.5,2.8] ∧ bp∈[0.60,1.05] ∧ rsi6∈[55,80] ∧ r30∈[0.03,0.25]
实用: turnover∈[4,12] ∧ vr∈[1.0,2.8] ∧ bp∈[0.50,1.05] ∧ rsi6∈[50,80] ∧ r30∈[0.00,0.30]

# ── 排序：蓄势画像贴合分（越贴事件组 P50 越高）──
PROFILE = {turnover:(2.20,4.54,9.74), vr:(0.82,1.22,1.96), bp:(0.42,0.71,0.93),
           rsi6:(45.5,58.6,71.7), dist_lo60:(0.147,0.284,0.483),
           r30:(-0.033,0.083,0.236), ma5_20:(-0.012,0.028,0.072)}
W       = {turnover:.62, vr:.56, bp:.51, rsi6:.48, dist_lo60:.47, r30:.44, ma5_20:.41}  # Σ=3.49
score   = Σ_k W[k] * (1 - clip(|x_k - P50_k| / (P75_k - P25_k), 0, 1)) / Σ W
# 输出 = score 降序；锐利展示前 8（带内可达 25+），实用展示前 12

# ── 标记（只提示不剔除）──
if pct_chg >= lim - 1.0: tag = "⚠️近板"
```

### 2.6 输出字段

| 字段 | 说明 |
|---|---|
| `code` | `300488.SZ`（**后缀式**，非 DB 内的 `sz300488`） |
| `name` | 股票名 |
| `turnover / vr / r30 / rsi6 / bp / dist_hi60` | 见 §2.4 |
| `zl` | 主力净额（万元，东财最新可得日，可能 n/a） |
| `score` | 蓄势贴合分（**与先手分不是一套**） |
| `tag` | `⚠️近板` / 空 |
| 价位块 | 昨收 / MA5 / MA10 / MA20 / 60日高 / 今涨停（全部来自 `daily.close`，未复权） |
| `pool[档]` | **全带内代码清单**（不只是展示前 N）← 盘中重排必须用它，否则漏掉排名靠后的赢家 |

JSON 顶层：`{status, asof, n_universe, tiers:{档:{n_gate,n_show}}, n_cand, stale_days, text, pool}`

### 2.7 跑批时机与失败处理

| 场景 | 处理 |
|---|---|
| 定时 | launchd `com.zenghui.sop.liupan_scan`，**18:35 周一至五**（T-1 收盘后） |
| 外置盘未挂载 | `status=no_disk`，页面显示「数据盘未挂载」，**不返回空池冒充无候选** |

## 3. 盘中：动量与先手分（`liupan_auction_rank.py`）

### 3.1 候选池载入（两条路，禁自拼阈值）

| 路径 | 命令 | 特点 |
|---|---|---|
| 默认（盘前池） | `liupan_scan.py --tier 锐利 --json` → `pool['锐利']` | T-1 静态，快（~3.5s），**看不到当天新热点** |
| 实时池（`--live`） | `liupan_live_scan.py --tier 锐利 --json` | 全市场重筛，通道 A 蓄势 + 通道 B 动量，~10-20s |

实时池细节：
- 通道 A = **同源复用 `liupan_scan`**（禁实时价重算 —— 否则出现「跌停但 BOLL 在带内」）
- 通道 B（当日动量）：`pct∈[3.0,9.8] ∧ turn∈[4,60] ∧ vr∈[2,50] ∧ 站上均价 ∧ pct < lim-0.3 ∧ 所属行业在「强板块」`
- **强板块门**：`板中位涨幅 ≥ 1.2% ∧ 板内涨停 ≥ 3 家`，否则 `status=no_sector` 整体不推

### 3.2 实时数据源与刷新

| 项 | 值 |
|---|---|
| 源 | 腾讯快照 `qq_snap.snapshot(secids)`（一次批量拉全市场） |
| 字段 | `pre`（昨收）/`price`/`turnover`/`pct`/`name`/`avg` |
| 盘中拉取上限 | 盘中 >200 只/次会 raise → 必须 `QQ_SNAP_ALLOW_INTRADAY=1`（脚本已 `setdefault`） |
| 刷新频率 | 实时池 launchd 每 **10 分钟**（09:33…11:23、13:03…14:53）；单票重排按需 |
| 板块成分 | 每个候选行业拉全成分快照（≤400 只/行业） |
| 耗时实测 | 22 只池 + 板块层 ≈ **8.6s**；39 只池 ≈ 87s（视板块数） |

### 3.3 动量指标与计算

| 指标 | 公式 | 说明 |
|---|---|---|
| `open_pct` | `(price / pre - 1) * 100` | 竞价窗 = 高开%；盘中 = 涨幅 |
| `turn` | 快照 `turnover`% | 竞价 = 竞换；盘中 = 当前累计换手 |
| `room` | `lim - open_pct` | 距涨停空间% |
| `zt`（已涨停·买不进） | `open_pct >= lim - 0.3` | **不是** `pct>=9.5%` 近似 |
| `lim` | 按板块 10 / 20 / 30 | 板块层统计用 `_lim_pct`；**单票 scoring 的 lim 同源** |
| 板块 `med` | 行业内全成分 `pct` 中位数 | 申万行业（`stock_info.industry`） |
| 板块 `zt_density` | `涨停家数 / 成分数` | 涨停判 `pct >= _lim_pct - 0.3` |
| `zb`（昨炸板） | 昨日 `high ≥ limit_up*0.999 ∧ close < limit_up*0.999` | 本地库补算 |
| `zt5/zt10/zt20` | 近 N 日 `close >= limit_up*0.999` 次数 | 本地库补算 |

### 3.4 先手分（完整公式）

```
先手分 = 0.45 × nz(open_pct, A_OPEN)
       + 0.30 × nz(turn,     A_TURN | A_TURN_ID)     # 按模式切换
       + 0.25 × nz(sect_raw, A_SECT)
       − penalty

nz(x, lo, hi) = clip((x - lo) / (hi - lo), 0, 1)      # 固定锚点线性归一，超界截断
                                                    # x=None 或 hi<=lo → 0.5（中性）

sect_raw = 0.6 × nz(sect_med, -3, 6) + 0.4 × nz(sect_zt_density, 0, 0.15)
           无板块数据 → sect_raw = None → sect_score = 0.5（中性）

penalty = 0.30 × [昨炸板]
        + 0.06 × max(0, zt10 - 1)
        + 0.03 × max(0, zt20 - 1)

score_adj = 先手分 - penalty          # ← 排序用这个
```

**锚点（绝对刻度，跨日可比）**

| 锚点 | 值 | 语义 | 维护 |
|---|---|---|---|
| `A_OPEN` | **(−2.39, 1.93)** | 高开% / 盘中涨幅 | 23,680 票次 P5~P95；**每 6 个月重算，改必记档** |
| `A_TURN` | (0.0, 0.25) | 竞价换手% | 同上 |
| `A_TURN_ID` | (0.0, 15.0) | 盘中换手% | 盘中量纲不同，单列 |
| `A_SECT` | (0.143, 0.267) | 板块原始强度 | 同上 |

**水位标签**：`≥0.60 强` ｜ `0.45~0.60 中性` ｜ `<0.45 弱（今日无先手票）`

**整池水位门（治「全池低开时的伪第一」）**

| 门 | 阈值 | 动作 |
|---|---|---|
| `weak_pool` | 全池**最高**高开 < 0.0% | 🔴 不出首选，只列「谁最不跌」 |
| `soft_weak` | 全池高开**中位** < −1.0% | ⚠️ 只列不荐 |

**🔴 已知缺陷（必读）**：盘中模式复用竞价锚点 `A_OPEN`，而盘中涨幅常态 >1.93% → **`nz(open_pct)` 恒顶格 0.450**。
- 例：盛天网络 11:19 得 0.815，其中 **0.450（55%）来自涨幅顶格**，真实强度部分只有 0.365。
- App 展示必须同时给出「顶格占比」，否则用户会把「涨得多」误读成「先手强」。
- 修复方案（**待确认**）：单列 `A_OPEN_ID ≈ (−5, +5)`，按盘中 P5–P95 重标；改前须记档「历史分不可比」+ 跑 `--selftest`。

### 3.5 排序与并列

| 项 | 规则 |
|---|---|
| 排序键 | `score_adj` 降序 |
| 可分榜 | `buy`（未涨停）/ `locked`（已涨停·仅观察） |
| 展示条数 | `buy[:8]`，`locked[:5]` |
| 并列处理 | **未定义**（Python `sort` 稳定 → 同分按池内原序）→ **待确认**（建议：同分按 `turn` 降序，再按 `code`） |
| `hot`（🌅板块异动） | 板块 `zt>0` 的行业，按 `(-zt, -med)` 排序，展示前 5 |

### 3.6 重算 / 剔除 / 降权时机

| 动作 | 触发 |
|---|---|
| 重算 | 09:26 竞价一次；盘中每 10 分钟（launchd）；用户手动刷新 |
| **剔除**（进 `locked`） | `open_pct >= lim - 0.3` 已涨停 → 买不进 |
| **降权** | 昨炸板 −0.30（沉底）｜zt10 每多 1 板 −0.06｜zt20 每多 1 板 −0.03 |
| **不降权但标注** | 板块背离（板中位<0 ∧ 涨停≥3）｜`⚠️近板`｜昨涨停(`t1zt`) |
| 池空 | 返回空 text（静默），不推送 |

## 4. 买入决策辅助（非自动交易）

### 4.1 下单前我看的字段（顺序即优先级）

| # | 字段 | 用法 |
|---|---|---|
| 1 | `room`（距涨停%） | `<2%` 追高风险，`<0.3%` 买不进 |
| 2 | `score_adj` + 顶格占比 | 先手强度（拆掉 clip 伪强） |
| 3 | `turn` | 活跃度；竞价 <0.05% 偏冷 |
| 4 | `ind / sect_med / sect_zt / consist` | 板块共振 vs 个股独走 |
| 5 | `zb / zt10 / zt20` | 炸板、连板高度（惩罚来源） |
| 6 | 池 `asof` + `stale_days` | 池过期 = 结论作废 |
| 7 | `intraday_path.py` 七问 | 几点冲高/破均价/量能/动能衰竭 |
| 8 | `advice_gate --pair` | 四查 + 双向输出（**非否决权**） |

### 4.2 建议展示的预警

| 预警 | 触发条件 | 展示 |
|---|---|---|
| 🚫 已涨停买不进 | `open_pct >= lim-0.3` | 进 `locked` 区，不与可买混排 |
| ❗ 昨炸板 | `zb=True` | 分数已沉底 + 标签（含自高点回落%） |
| 🌅 板块异动 | 某行业竞价/盘中涨停 ≥1 家 | 顶部横条，显示 `行业 zt/n（票名）` |
| ⚠️ 板块背离 | `sect_med<0 ∧ sect_zt>=3` | 标签「背离·个股行情」 |
| ⚠️ 整池低开 | 最高高开 <0% | 顶部红字 + 不出首选 |
| ⚠️ 近板 | `pct_chg >= lim-1.0` | 候选池 `tag` |
| ⚠️ 高标博弈 | `zt10 >= 2` | 首选附注「追高风险高」 |
| ⚠️ 非竞价时段 | `>09:32` 且未显式声明 | 漂移告警 |
| ❓ 数据缺失 | 快照为空 / 盘未挂载 | `status=no_data`，**不静默降级为「无候选」** |

## 5. 数据与实现线索

### 5.1 路径

### 5.3 已知坑（每条都有血证）

| 坑 | 表现 | 正确做法 |
|---|---|---|
| **code 三族** | 前缀 `sz300488` / 后缀 `300488.SZ` / 裸 `300488` | 前缀=`daily/limit_price/minute_*`；后缀=`tech_factor_*/adj_factor/stock_info.industry`；JOIN 前必归一并断言单一格式 |
| **档位禁硬编码** | 硬编码 10/20 → ST 涨 4.9% 已板却判「未涨停」混进池；北交所 12% 被误判已涨停 | 一律 `limit_price.limit_pct` |
| **板块层 `_lim_pct` 仍硬编码 10/20/30** | 板块内 ST 涨停（5%）会被漏计 → `sect_zt` 偏低 | 🟡 **待确认**：板块层是否也改读 `limit_price` |
| **`daily.pct_chg` 是未复权** | 涨跌停/暴跌阈值失真 | 用 `COALESCE(daily_ind.pct_chg, daily.pct_chg)` |
| **绝对价位** | 后复权价当昨日收盘 → 差几倍 | 昨收/MA/涨停价一律 `daily.close`（未复权） |
| **`limit_price.prev_close` 含除权** | 不能用来校正前一日 `daily.close` | 用 `daily_ind` |
| **列名骗人** | `今日主力净流入额（万元）` 实存单位是「元」 | 显示 ÷1e4 |
| **VARCHAR 日期混格式** | `'2026-09-10'` 与 `'20260521'` 同列 → 裸 `max()` 取到假最大值 | 先归一 |
| **只读连接 WAL** | 他进程写库时 `read_only=True` 读到旧快照 → 误判「数据丢了」 | 用写连接 `CREATE TABLE bak AS SELECT` 复核 |
| **当日分钟数据 21:00 后才入库** | 盘中查 `minute_1min` 当日 `bars=0` | 盘中用腾讯快照；历史用 `minute_1min` |
| **`minute_1min` 多资产混合** | 指数/ETF/板块混在股票里 | 取股票必 `market IN ('hs','bj')` |
| **新浪 1min 截断** | 回放时首根 bar = 13:56（`datalen=320` 只覆盖 1.33 日） | 首根 >09:32 或末根 <14:55 → 回退本地库，仍残则拒 |

| **`QQ_SNAP_ALLOW_INTRADAY`** | 盘中 >200 只/次直接 raise | 已 `setdefault("1")`，别删 |
